S122 Part 7 [ruling 8]: the client's Critical Path view. ONLY phase name/sort/start/finish, task title/sort and the projected finish, and only when Critical Path is on, for a linked client with full access. The return type has no column for float, criticality, assignees, descriptions, durations, status or history; it is the client's ONLY Critical Path read (tasks, settings and finish history have no client policy).
