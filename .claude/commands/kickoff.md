# Session Kickoff

You are starting a new FrameFocus development session. Before writing or editing any code, do the following in order:

1. Read CLAUDE.md to refresh project rules and conventions.
2. Read CLAUDE_MODULES.md for the module structure.
3. Read STATE.md to understand current state — what's complete, in progress, and pending.
4. Read TECH_DEBT.md so you know what existing issues to avoid stepping on.
5. List the contents of `docs/sessions/` and read the most recent session plan file (the one with the highest session number, e.g. `session09.md`).
6. Run `git status` and `bash scripts/session-start.sh` to see uncommitted work and recent commits.

Then give me a kickoff summary in exactly this format:

**Where we are:** one short paragraph from STATE.md.
**This session's goal:** one sentence from the session plan.
**First three concrete steps you propose:** numbered list.
**Anything that looks risky, unclear, or worth flagging:** brief bullets, or "nothing flagged."

Wait for my confirmation before making any edits.
